  ```html
  <title>Session player</title>

  </x-dc>
  <script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1280,"height":800}}'>
  class Component extends DCLogic { renderVals() { return {}; } }
  </script>
  </body>
  </html>
  ```
- Keep the `support.js` line verbatim. Close every element, quote every attribute.
  Root is fixed px at the artboard size (these are desktop-window mockups).
- **No Tailwind, no CDN, no network** except a Google Fonts `css2` `<link>` inside
  `<helmet>`. Styles are inline `style="…"`; only page basics in `<helmet><style>`.
  Flex/grid with `gap` for layout.
- `{{hole}}` is a dotted lookup into `renderVals()` only, never an expression.
  Repeats: `<sc-for list="{{items}}" as="item" hint-placeholder-count="3">`.
  Branches: `<sc-if value="{{cond}}" hint-placeholder-val="{{true}}">`. Static
  copy stays literal markup. Few `data-props` tweaks, only real levers (e.g. theme
  light/dark, accent).
- Icons: inline stroke `<svg>`, never emoji. Real `<button>`/`<input>`/`<label>`.
  No `<iframe>`, no script-built DOM, no global keydown handlers.
- Images: footage stills link by relative path, `assets/<name>.jpg`, with the
  files in `canvas\project\assets\` (≤200 KB each, 960 px wide JPEG). The lead
  decides whether real footage gets uploaded; design so a neutral placeholder
  also reads.
- `canvas.json`:
  `{"v":3,"createdOnFiles":{"v":1,"at":"<now RFC3339>"},"title":"ChirpTime redesign","launch":{"view":"canvas"},"pages":[{"id":"widget","name":"Widget"},{"id":"viewer","name":"Viewer"},{"id":"edit","name":"Edit + export"}],"boards":{"Main.dc.html":{"x":0,"y":0,"w":1280,"h":800,"title":"Player — direction A","page":"viewer"}, …},"order":[…],"notes":{}}`
  Frames 80 px apart in a row, 120 between rows; every `.dc.html` you write is
  listed in `boards` and `order`. A note with `"kind":"title1"` may title a row
  (sits ≥223 px above it).
